# P1 amendment 1.1 — sampled handoff semantics

## Why revision is required

In a recurring autonomous rollout, the independently simulated `actual` and
`fresh` policies diverge after their first different action. Subsequent
`J_fresh - J_actual` terms are then policy-value differences from different
states, not fresh-versus-stale actions at the same arrival state and time. The
original prose requires the latter interpretation. P1.0 exact recurring values
and all existing artifacts remain preserved.

## Versioned clarification

P1.1 records two distinct estimands and never substitutes one for the other:

1. **Operational recurring frontier.** `J_actual` is the deployable recurring
   plan/act process and remains the target for budget regret and M0–M5 transfer.
2. **Matched one-handoff decomposition.** From a shared root, `actual(k)` and
   evaluation-only `fresh(k)` traverse the identical reflex prefix to the same
   arrival state/time. `fresh` substitutes the same-budget recommendation at
   that handoff without a second delay. `instant` applies the same computation
   at launch. After the one intervention, all arms use the same frozen
   continuation rule. The named identity is checked episodewise for this local
   estimand.

No claim may be made that the sum of local handoff effects decomposes recurring
policy value unless a separately preregistered performance-difference weighting
establishes that link.

P1.1 uses observed per-decision latency rather than `nu_h * k`. With launch
phase `phi_i` in `[0, 1)` and environment event rate `nu_e`, the number of events
before completion is

```text
d_i(k,h) = floor(phi_i + nu_e * T_i(k,h)).
```

Completion exactly on an event boundary occurs after that event. Runtime
records include fixed overhead and jitter. Hardware utility cost is cumulative
per episode and additional to the effect of world advancement; latency is not
subtracted twice.

Irreversibility remains outside the return identity. At the longer of base and
candidate arrival times, it compares the actual reflex prefix with the same
reflex through base arrival followed by a frozen safe/recovery policy.

## Independent review and controls

The v2 theory, heuristics, and literature reviews required this repair before a
P1.1 verdict. Required controls include launch-time charging, per-lane work,
random phase, untouched oracle/evaluation units, paired context-level upper
bounds, explicit whole-context splits, causal descriptor whitelisting,
planner/reflex match and mismatch, and a Finding-the-Time-to-Think-style gate.

## Falsification and experiment version

P1.1 is invalid if matched arms differ before arrival, the episodewise identity
does not close numerically, pending work is free, observed timing is replaced by
a product-only construction while noncollapse is claimed, or oracle selection
and regret evaluation reuse the same units. Runs using this amendment must use
an amendment identifier containing `p1-1.1`; P1.0 remains on its original
scientific specification plus the scheduling-only portfolio amendment.
